# Rich PS Website

Website resmi untuk Rich Private Server (Growtopia Private Server).

## 🚀 Deployment

### Via Vercel (Recommended)

1. Fork atau clone repository ini ke GitHub
2. Login ke [Vercel](https://vercel.com) dengan akun GitHub
3. Klik "Add New Project" → Pilih repository ini
4. Biarkan pengaturan default → Deploy

### Via GitHub Pages

1. Upload semua file ke repository GitHub
2. Aktifkan GitHub Pages di Settings → Pages → Branch `main` → Folder `/ (root)`
3. Akses di `https://[username].github.io/[repo-name]/`
