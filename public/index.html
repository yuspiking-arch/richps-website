How to Play

Choose your platform below to start playing Rich PS!

Rich PS Mobile APK

  1. Uninstall Real Growtopia if you have it
  2. Restart your device (optional but recommended)
  3. Download & install Rich PS APK
  4. Open Rich PS and login with your account
Download APK

Windows (Hosts)

  1. Press Win+R → paste C:\Windows\System32\drivers\etc
  2. Open hosts with Notepad (Admin)
  3. Add these lines:
91.134.85.13 growtopia1.com 91.134.85.13 growtopia2.com 91.134.85.13 www.growtopia1.com 91.134.85.13 www.growtopia2.com
  1. Save → launch Growtopia

PowerTunnel (Android)

  1. Install PowerTunnel APK
  2. Open → Plugin → Hosts → Open Settings
  3. Enter URL:
https://dash.gtps.cloud/android/616
  1. Back, click "CONNECT", open Growtopia

Hosts Go (Android)

  1. Install Hosts Go (No Root)
  2. Open → Hosts Editor → enable → Download Hosts
  3. Enter URL:
https://dash.gtps.cloud/android/616
  1. Apply, start protection, open Growtopia

Virtual Host (Android)

  1. Install Virtual Host APK
  2. Download Hosts File below
  3. Open Virtual Host → SELECT HOSTS FILE
  4. Select the downloaded file RichPS.txt
  5. Open Growtopia

Mac

  1. Finder → Go → Go to Folder → /private/etc/hosts
  2. Copy to Desktop, edit, then add:
91.134.85.13 growtopia1.com 91.134.85.13 growtopia2.com 91.134.85.13 www.growtopia1.com 91.134.85.13 www.growtopia2.com
  1. Save and move back → start Growtopia

Surge5 (iPhone)

  1. Install Surge5
  2. Import Profile URL:
https://dash.gtps.cloud/ios/616
  1. Allow VPN Configuration → Connect → Open Growtopia
